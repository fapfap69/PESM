# PESM Basic Examples

Simple examples demonstrating core PESM features.

## Examples

### 1. Hello World (`hello_world.php`)
Basic script execution with MESSAGE interrupt.

```bash
php hello_world.php
```

**Features:**
- Variable assignment
- String concatenation
- MESSAGE interrupt

### 2. Calculator (`calculator.php`)
Functions, expressions, and control flow.

```bash
php calculator.php
```

**Features:**
- Function definitions
- Function calls
- Arithmetic operations
- IF statements

### 3. Arrays and Loops (`arrays_loops.php`)
Data structures and iteration.

```bash
php arrays_loops.php
```

**Features:**
- Arrays and nested arrays
- FOREACH with arrays
- FOREACH with ranges
- WHILE loops
- STRUCT definitions
- Property access (dot notation)

## Running Examples

All examples can be run directly:

```bash
cd examples/01-basic
php hello_world.php
php calculator.php
php arrays_loops.php
```
